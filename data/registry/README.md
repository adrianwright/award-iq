# Award IQ registry

`funding_registry.yaml` is the canonical record for the active synthetic Award IQ scenario and
suggested resource names. It pins the scenario date, notice, deadline, match values, owners, and
task IDs. Structured operations tables are generated by
`data/fabric/funding_ops/generate.py`.

The original `registry.yaml` and `loader.py` describe the retained clinical source-project fixtures;
they are not used by the Award IQ funding API or UI.
