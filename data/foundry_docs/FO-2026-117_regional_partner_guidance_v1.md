# Regional partner commitment guidance

Amendment 2 requires a signed commitment letter from a qualifying regional public partner to be
included with the application. Historical correspondence or a letter from an earlier proposal is
not current consent. The Regional Transit Authority is a potentially qualifying partner, but the
current FO-2026-117 evidence set contains no signed 2026 letter. Partner qualification and receipt
of a current letter are separate checks.
