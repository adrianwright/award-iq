# Limitations

- All three funding scenarios, institutions, people and workflow records are fictional. The hero
  date is November 16, 2026; external guidance is a packaged snapshot, not current agency advice.
- Connected Fabric, Foundry and Work IQ operate on synthetic records. Live provenance is reported
  separately from packaged evidence. Work IQ is opt-in and requires actual tenant indexing/access.
- The application creates no tasks, email, notifications, meetings, approvals, awards or submissions.
  `Pursue - pending` remains a recorded human disposition, not an approval.
- Structured checks constrain model output but cannot guarantee every generated statement.
  Unknown evidence must be reviewed by a person.
- Deployment is operator-assisted: baseline parameters do not bind optional live intelligence/Work IQ.
  Entra, certificate/Key Vault, Fabric bootstrap, SQL permissions and M365 document setup remain
  prerequisites. Preview API availability, model quota, region capacity and billing can block setup.
- No production readiness, compliance or grant eligibility guarantee is claimed.
