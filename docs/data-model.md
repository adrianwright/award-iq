# Award IQ funding data model

The active funding ontology is `data/ontology/funding_ontology.yaml`. Its Fabric-compatible
synthetic dataset lives in `data/fabric/funding_ops/` and is regenerated by
`data/fabric/funding_ops/generate.py`. Resource names use the `award-iq` slug; the suggested
Fabric-compatible dataset name is `award_iq_fabric_funding_ops`.

The operations model includes `amendments`, `approvals`, `budget_lines`, `community_metrics`,
`eligibility_criteria`, `funding_opportunities`, `match_sources`, `partners`, `people`,
`prior_proposals`, `program_performance`, `scheduling_slots`, `staff_workload`, and `submissions`,
plus proposal task state. `data/fabric/funding_ops/data_dictionary.md` defines the table grain and
calculation basis.

## Ground-truth rules

- FO-2026-117 has a pinned as-of date of 2026-11-16 and deadline 2026-12-16.
- Select the latest effective amendment on or before the as-of date; Amendment 2 supersedes
  Amendment 1 and controls the 25% match and partner-letter requirements.
- Match is 25% of $9,000,000 total eligible project costs ($2,250,000). Sum only Confirmed sources.
  The 2026 capital-plan $1,800,000 is confirmed; proposed reserve funding remains proposed; gap
  `$2,250,000 - $1,800,000 = $450,000`.
- A missing current partner letter is unresolved evidence. The 2024 Regional Transit Authority
  letter is a lead only.
- An approval/review record is not an approval event. Funding decisions remain with authorized
  humans; tasks are never created by the evaluator.

The original clinical data model is not used by the Award IQ frontend or funding API.
