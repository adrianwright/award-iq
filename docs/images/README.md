# Archived source-project images

The PNGs in this directory illustrate the former clinical-trial proof of concept. They are
intentionally not embedded in active Award IQ docs or the site; their oncology/patient visuals do
not describe the grant application. Do not relabel or reuse them as grant screenshots.

The Award IQ interface is runnable from the root README. No static clinical screenshot is presented
as evidence of the funding workflow. Add new synthetic Award IQ screenshots only after capturing
and verifying the actual UI, with no credentials or real user data.
